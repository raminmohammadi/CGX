## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please **do not open a public issue**. Instead, please report it privately.

### How to Report

* **Preferred Method:** Use GitHub's private vulnerability reporting feature:
  1. Go to the [CGX Security Advisories tab](https://github.com/raminmohammadi/CGX/security/advisories/new) (or navigate to your repository's **Security** tab -> **Advisories** -> **Report a vulnerability**).
  2. Fill out the form with details about the vulnerability.

* **Alternative Method:** If you cannot use GitHub advisories, you can reach out via email to the maintainer at [Rey.mhmmd@gmial.com]. 

### What to Include
To help us triage and reproduce the issue efficiently, please provide as much of the following information as possible:
* Type of vulnerability (e.g., SQL injection, remote code execution, cross-site scripting).
* Full paths of source file(s) related to the vulnerability.
* Step-by-step instructions to reproduce the issue (proof of concept).
* Any potential impact or risk assessment.

### What to Expect
* **Acknowledgment:** You can expect an initial response acknowledging receipt of your report within **48 hours**.
* **Status Updates:** We will provide regular updates on our progress as we investigate and validate the vulnerability (typically every week until a fix is deployed).
* **Fix & Disclosure:** If the vulnerability is accepted, we will work on a patch, coordinate a release timeline, and credit you upon disclosure (unless you prefer to remain anonymous). We aim to handle disclosures responsibly following coordinated vulnerability disclosure guidelines.

Thank you for helping keep this project and its users safe!
